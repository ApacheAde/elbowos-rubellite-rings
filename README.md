# Rubellite Rings

Full-colour Python 3 neon hoop-thread arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a ruby shard through falling, swaying rings.
Thread the inner hoop for a streak. Clip the rim and the streak snaps.

A / D or ← → to slide. R reset. Esc quit.

## Play

```
pip install -r requirements.txt
python3 rubellite_rings.py --play
```

## Record a 9:16 reel

```
python3 rubellite_rings.py --record
```

Writes `/home/workdir/artifacts/RUBELLITE_RINGS_ElbowOS.mp4` (1080×1920, 15s, 30fps, h264).
